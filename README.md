# GELATO CREAMO

## Descripción General

Gelato Creamo es una página web interactiva para una heladería ficticia. El sitio permite a los usuarios explorar los productos disponibles, seleccionar sabores de helado, personalizar su pedido y simular un proceso de compra mediante un carrito interactivo.

El proyecto simula la experiencia de compra en línea de una heladería, facilitando la visualización de productos y la gestión de pedidos de forma dinámica e intuitiva.

## Funcionalidades

* Página de inicio con presentación de la heladería.
* Visualización de productos mediante tarjetas interactivas.
* Selección de sabores de helado para añadir al carrito.
* Carrito de compras dinámico.
* Incremento y disminución de la cantidad de helados.
* Opción de agregar conos extras.
* Opción de agregar toppings adicionales.
* Actualización automática del pedido según la selección realizada.
* Formulario de pago con nombre y correo electrónico.
* Selección del método de pago (efectivo o tarjeta).
* Sección de contacto con información de la heladería.
* Visualización de horarios de atención.
* Integración de mapa de ubicación.
* Acceso a redes sociales.
* Imágenes y elementos interactivos para mejorar la experiencia del usuario.

## Estructura del Proyecto

'index.html' → Página principal del sitio. Presenta la identidad de Gelato Creamo, información destacada de la heladería e imágenes interactivas que introducen al usuario a la experiencia del sitio.
'sabores.html' → Catálogo de productos donde se muestran los diferentes sabores de helado mediante tarjetas interactivas. 
Los usuarios pueden seleccionar los productos que desean comprar y agregarlos al carrito.
'carrito.html' → Página encargada de la gestión de pedidos. Permite visualizar los productos seleccionados, aumentar o disminuir cantidades, agregar conos extra y toppings, completar los datos del cliente y seleccionar el método de pago (efectivo o tarjeta).
'contacto.html' → Página de contacto que incluye información general de la heladería, horarios de atención, ubicación mediante mapa integrado y enlaces a redes sociales.
'styles.css' → Archivo que contiene todos los estilos visuales, colores, tipografías y diseño responsivo del sitio web.
'app.js/ → Archivo JavaScript que controla las funcionalidades dinámicas e interactivas del sitio, incluyendo la lógica del carrito de compras y la interacción con los productos.
